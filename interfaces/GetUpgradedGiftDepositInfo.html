Interface GetUpgradedGiftDepositInfo

Returns information needed to deposit an upgraded gift from the TON wallet of the current user to a Telegram account. Use sendTonWalletTransfer to complete transfer of the gift. The gift will be received by the new owner with a message about the gift after the transfer is confirmed in the blockchain. Request type for Tdjson#getUpgradedGiftDepositInfo.
